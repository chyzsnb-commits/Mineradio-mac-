# Mineradio 2.0 公开发布审计

审计日期：2026-07-23

## 结论

当前分支可作为 **2.0.0 双架构技术候选包**，但在完成签名、公证、隐私联系信息和音乐平台授权确认前，不应标注为“已完成合规审查”的正式公开版本。

## 已完成

- 正式产品身份：`mineradio`、`2.0.0`、`com.mineradio.desktop`，`internalBeta=false`。
- 汽水音乐后端、登录桥、本地 Cookie 数据库读取、Token/Cookie 导入、模拟客户端扫码与音频解密器已从公开分支删除。
- 登录凭据手动导入、导出在公开版关闭；支持平台的本机会话与 Spotify token 使用 Electron `safeStorage` 加密保存。
- 本地服务默认仅监听 `127.0.0.1`，并拒绝外部网页 Origin 调用本地 API。
- 匿名遥测在正式版完全不启动；崩溃记录、摄像头画面、麦克风音频和 AI 分轨结果不上传。
- 增加摄像头/麦克风用途说明、隐私说明、第三方组件说明和 MediaPipe Apache 2.0 许可证。
- 生产依赖执行 `npm audit --omit=dev` 后为 0 个已知漏洞。
- 已生成并验证 Apple Silicon arm64 与 Intel x64 DMG。

## 汽水音乐判断

原实现包含读取官方客户端 Cookie 数据库、要求用户粘贴会话 Cookie/Token、模拟官方客户端请求及解密受保护音频等行为。免责声明不能消除这些行为的账号安全、平台协议、隐私和内容授权风险，因此 2.0 公开分支采取的是删除，而不是继续保留后加提示。

## 正式公开前的阻塞项

1. **Apple 签名与公证**：本机没有有效 Developer ID Application 证书；当前 DMG 未签名、未公证，只适合内部验收。
2. **音乐内容与平台授权**：网易云、QQ、酷狗等接入包含非官方或未在仓库中提供授权证明的接口/播放链路。发布者必须确认平台接口授权、内容播放权、商标使用和用户账号会话使用范围；无法确认时应在正式公开版关闭对应联网播放能力。
3. **隐私主体信息**：发布下载页前补充运营者名称、联系方法、数据删除入口和永久隐私政策网址。
4. **第三方许可终审**：按最终 `app.asar` 和 `node_modules` 清单保存完整许可证/NOTICE，并确认 GSAP 等非 MIT 组件的分发范围。
5. **真机验收**：Intel Mac 仍需实机启动、搜索、播放、歌词、摄像头手势、麦克风唱歌模式和 AI 分轨验收。

本文件是工程发布审计，不替代律师对具体发行地区、平台协议和音乐版权的法律意见。
