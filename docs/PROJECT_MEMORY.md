# Mineradio 项目记忆

## 2026-08-15：Electron 包完整性与本机 Safe Storage 迁移边界

- bootstrap、Electron fuse wire、ASAR header、packed Safe Storage handoff、外置 recovery helper、controller 固定哈希与最终签名 App 必须由同一冻结源码构建并一起验收；任一源码、二进制、签名或包路径变化都会使旧 controller 失效，禁止跨候选复用。
- Mac 正式构建必须关闭 RunAsNode、`NODE_OPTIONS` 和 CLI inspector，开启 embedded ASAR integrity 与 OnlyLoadAppFromAsar；CookieEncryption 本轮明确保持关闭，避免与登录迁移叠加不可逆 Cookie 格式变化。Safe Storage handoff 必须保持 packed，不能放进可替换的 `app.asar.unpacked`。
- ad-hoc 包 CDHash 每次变化，本机覆盖更新必须采用无明文落盘、持久 journal、完整 App/userData 备份、进程静止、签名身份绑定和物理 Keychain 状态对账的可恢复迁移；任何失败都应按实际 marker fail-forward 或 rollback。成功后 guard、pending、completed 与 recovery 都必须清空，稳定 0600 native lock 文件保留。
- 迁移备份只能放在用户私有的 `~/Library/Application Support/Mineradio Migration/backups.noindex`，不能默认落到可能同步云端的 Desktop。首次创建每一级目录都要 fsync 自身与父目录，严格断电模型不能只依赖文件内容 fsync。
- 重复 App 要区分真实文件和 LaunchServices 历史注册：可逐一注销已确认的旧路径并 `lsregister -gc`，不得全库 `-delete`。备份 App 可以保留，但不得继续作为可索引/可启动的第二入口；目录构建继续放 `/private/tmp` 或 `.noindex`。

## 2026-08-14：唯一 App、临时构建与词境穿行动画边界

- macOS 会把桌面仓库里的 `dist/mac-arm64/Mineradio.app` 和 `/Applications/Mineradio.app` 同时交给 Spotlight，表现为两个完全同名图标。目录构建必须输出到 `/tmp/mineradio-performance-final.*` 或 `.noindex`；安装验收后只保留 `/Applications/Mineradio.app` 为可索引副本，不能靠全局重置 LaunchServices 掩盖重复文件。
- P11“词境穿行”现有五张歌词卡已经足够形成运动差异；新增动画只允许改变 position、rotation、scale、blur 和 opacity，不新增 CanvasTexture、mesh、后处理、RAF 或定时器。当前新增四类为景深接力、近景回卷、折页展开和坠落回弹，编排总数 16 套。
- 顺序换句必须从下一句上一帧的真实位置连续接入；反向换句和 seek 也不能从旧近景姿态大幅飞回。歌词总开关、跨曲 bridge 限幅与系统“减少动态”优先级高于任何入场效果，动画代码不得直接把隐藏卡片透明度写亮。

## 2026-08-14：摄像头亮度、双手缩放与手部模型边界

- 透视模式必须显示摄像头自身正常曝光。视频层只允许保留镜像与 `object-fit: cover`，不得再叠 `brightness()`、固定黑色遮罩或为了“电影感”统一压暗；需要提升歌词可读性时只处理前景文字自身，不改摄像头底图亮度。
- 手势推理输入必须保持采集源宽高比，最长边按性能预算缩放；不得把 16:9 摄像头强行压成 4:3。MediaPipe handedness 与掌心最近位置要共同参与双手槽位稳定，避免交叉或短暂遮挡后左右手跳槽。
- 双手缩放的产品语义已经锁定：两只张开手掌稳定出现后，以掌心距离直接控制缩放；当前参数为 140ms 接管、2.5% 死区、180ms 丢手保护。不得要求两只手同时捏合、模拟滚轮、加入长按拖动或惯性，也不得在同一双手手势中顺带按连线角度旋转；单手捏合旋转可独立保留。
- 透视与手势继续共用唯一 MediaStream，手部模型渲染层只消费识别后的 21 点坐标，绝不能另开摄像头或上传帧。自动化仍必须使用隔离 userData 与 fake camera。
- 手部模型库内置样式与用户模型是摄像头交互的视觉层，不影响手势判定。用户导入以自包含 GLB 为首选，也可接受所有资源均内嵌为 data URI 的 glTF；外链 buffer/纹理必须拒绝。模型只存本机 IndexedDB，保留文件大小、总量、数量、三角形、draw call、节点和纹理尺寸上限，删除必须可回退到经典流光。
- GLB 预检与实际 GLTFLoader 必须看到同一份 JSON、BIN 和纹理来源：拒绝重复或乱序 JSON/BIN chunk、未知 chunk、GLB buffer URI、场景/相机数量膨胀、多父节点 DAG 与按节点复用后超预算的 mesh。安全预算必须在 GLTFLoader 实例化对象前完成。
- WebXR Generic Hand 可作为 MIT 许可的内置实体手；未知用户模型只能做整手的掌心位置、方向和大小跟随，不可凭骨骼名称猜测并强行重定向，以免不同 rig 发生断裂。若未来支持真正逐关节蒙皮，必须先建立明确的骨骼映射与样例验收。

## 2026-08-13：词境穿行参考视频边界

- “词境穿行”是独立视觉预设，但歌单行为必须与“音域回响”完全一致：底栏歌单按钮打开视觉控制台中的普通 DOM 歌单；不得显示、命中或通过滚轮/右键操作 3D 歌单架。P10/P11 互切必须共享唯一的歌单 dock 原宿主记录；进入和退出 P11 不得改写用户原有的 3D 歌单架固定状态，歌单页也只能在对应控制台 tab 激活时显示。
- 参考视频里的歌词换句不是逐字打字。整句先排好不同字号，普通转场约 0.6–1.0 秒：新句从深处推进到焦面，旧句继续越过焦面放大、失焦、降透明，两句保留短暂重叠；不得退化成简单淡入淡出或逐字擦除。
- 用户后续明确要求复刻参考视频里的鼠标互动。最终边界是只让封面响应命中：约 8% 弹性放大、随指针轻倾，移开后约 0.35–0.55 秒回弹；歌词不跟随鼠标、不排斥、不发光。另设“360° 词境漫游”控制整座封面+歌词舞台，不能和封面 hover 混成一个开关。
- 该预设必须遵守全局歌词开关；无封面歌曲不能沿用上一首封面；快速拖动进度条时只低频更新当前歌词纹理，松手后才补齐前后景深层，不能每跨一行重建五张大纹理。
- 词境穿行必须实时遵守歌词字号、字体、字重、字距和翻译设置；“当前/双行/多行”翻译语义与主舞台一致。该模式固定五层空间卡，不读取歌词行数，所以行数控件必须明确禁用并在离开 P11 后恢复，不能静默让滑杆无效。
- 用户已明确用“逐字流光”替换旧“跟唱明暗”：当前句原文底色从一开始就保持正常颜色，未唱部分绝不能变灰或压暗；其上再叠一层更亮、保留用户选定色相的光，从左到右跟随演唱平滑覆盖到正在唱的字。QQ QRC / 网易 YRC 必须使用真实逐字时间和 P11 混合字号、字重、字距、分块间距后的真实像素边界；普通 LRC 才允许按行平滑估算。译文保持独立透明度，不被横向扫亮；该效果默认开启。
- 全局图片、视频和专辑封面壁纸必须在 P11 透出，P11 只保留约 16% 的大气暗层；纯色、窗口透明或毛玻璃不能被误判为媒体壁纸。P11 进入时要保存 `scene.background`，退出时恢复，但切入 P10 时必须让音域回响接管背景，不能反向覆盖 P10 本帧已经建立的大气色。
- 顶部全局“自由镜头”与 P11 自己的“360° 词境漫游”是两个独立交互：全局 R/WASD/鼠标/K 必须真的移动相机穿行 P11，舞台固定在世界中而屏幕暗层跟随相机；P11 只能接管在本预设里显式开启的自由镜头，不能继承其他预设或上次启动保存的 locked 姿态。K 回正结束时舞台同步到位，禁止再出现第二段漂移。
- 360° 词境漫游复用 Emily 的同一组 `gestureRotation` / `gestureZoom`，双手张开收拢直接缩放 55%–190%，连线转动控制旋转；关闭或重开必须回正，不能带回其他预设的旧角度。摄像头仍由“手势触碰”显式开启，按钮文案必须说明这一前置条件。
- 换句编排不能长期只有左右/缩放三种；当前至少保留 12 套侧入、景深、上升、斜切、环绕、横扫、漂浮与蓄力穿越。跨曲必须冻结旧句布局与进度，在音频/歌词等待期保持低亮动态桥接；自动换源 token 要续接同一转场，歌词到齐后再进入 settle，禁止旧歌词回亮或突然硬切。
- 360° 舞台允许翻到背面，但封面和文字不能镜像；双面材质必须在 shader 里按 `gl_FrontFacing` 校正背面 UV。跨曲一旦遇到本地文件失效、音源被禁用、无 URL、启动失败或异常等终止路径，必须取消当前转场，禁止永久卡在 bridge 低亮态。

## 2026-08-11：稳定版上的选择性融合边界

- 权威产品基线是已恢复的原稳定 App，对应源码提交 `e3b77b9aafcf16e07a2b5687329d061ab6fce054`。以后不得把 PR #111 或后续移植线整版覆盖到 App；只能按用户逐项点名迁移。
- 音域视觉只保留原版“音域回响”。可以融合移植版的大方块观感和双手缩放手感，但不能带入“音域地形”“音域回响·WE”或其他移植模式。
- 悬浮方块尺寸边界固定为：100% 是原版黄金默认，200% 是移植版大方块观感。只能缩放现有 InstancedMesh 实例，不能增加方块数量或 draw call，性能优化不能牺牲质感。
- 双手缩放保留原有 30FPS Worker、双手身份稳定、180ms 丢手保护和方向映射；双手张开/收拢必须直接缩放音域内容，绝不能复用滚轮相机或加入目标/显示相机惯性。鼠标长按拖动和滚轮保持原版即时镜头手感。
- 底部播放器的歌曲信息、音质、红心与“+”必须保持同一行。超长歌名只允许省略，不能把红心或“+”换到下一行。
- 背景区不再显示“封面 / 裁切 / 清除”三个按钮，也不要恢复背景裁切专用弹窗。图片/视频背景以及原有位置、缩放滑条可保留；歌曲封面裁切是另一项能力，继续保留。
- 这批改动未获用户确认前，不覆盖 `/Applications/Mineradio.app`；先在隔离分支构建和验收。

## 2026-08-12：本地更新、唱歌音质与活跃统计边界

- 唱歌模式关闭时必须完全旁路实时人声分离和变调；开启实时唱歌模式时，Worklet 未就绪前不能把粗糙的 Biquad 降级分离直接当作首帧输出，后续优化应先保持原声直通，再在处理器就绪后短交叉淡入。
- 本机没有 Developer ID，完整 ad-hoc 构建的 cdhash 每次都会变化，直接覆盖会触发 `Mineradio Safe Storage` 授权并暂时读不到平台登录。取得稳定正式签名前，本地更新必须由旧 App 在内存中解密、由新 App 重新加密，禁止把 Cookie 明文落盘、删除密钥后让用户重登，或替换签名包里的单个 `app.asar`。
- 2.0 正式版的匿名遥测保持关闭。旧统计后端只实现同时在线、DAU、WAU、MAU、累计安装/下载、版本分布和 14 天趋势，没有 YAU；若未来恢复统计，必须先明确征得用户同意并重新定义可靠的活跃心跳。

## 2026-08-13：性能档与官方封面边界

- “自动 / 省电 / 均衡 / 高性能”是当前运行态的性能预算，切换必须立刻生效，不得要求用户重启。WebGL 在 Apple Silicon 上固定使用系统默认 Metal 设备；四档只动态调整帧率、分析频率和视觉负载。
- 性能设置不再拥有重启弹窗或独立 GPU 偏好，但软件更新完成后的通用重启桥必须保留，不能因为去掉性能重启而误删。
- QQ 官方封面优先使用搜索 API 返回的专辑 MID URL。MR 图标曾出现于《手写的从前》，根因是自动验收在真实 profile 写入了单曲自定义封面，不是 QQ 返回错误；已只删除 qq:002u8ZOM4C7QF4，禁止清空其他用户自定义封面。
- 所有会写 localStorage、IndexedDB、登录态、封面或视觉配置的自动验收都必须使用隔离 userData。真实 profile 只允许在用户明确要求下做定点、可回退的数据修复。

## 2026-08-14：透视背景与共享摄像头边界

- “透视模式”是“背景（所有预设通用）”里的全局背景能力，不是新的视觉预设。开启后摄像头画面只做底图，默认舞台的歌词/封面、粒子、P10“音域回响”和 P11“词境穿行”必须留在前景；关闭后恢复用户此前选择的图片、视频或颜色背景，不能要求重启。
- 背景区的 6 枚快捷色块已经永久移除，不要再加回；主调色板和“默认”入口继续保留，空出的整行用于透视模式。
- 手势识别和透视必须共享同一条 MediaStream，以 `gesture` / `perspective` owner 管理生命周期。两个功能并存只能采集一次；透视加入时可提升画质，透视退出但手势仍在时应降回手势档，最后一个 owner 释放后才停止轨道，禁止互相抢占摄像头或重复弹授权。
- 摄像头必须先经过 macOS 原生权限 gate，再调用 `getUserMedia`；拒绝、设备缺失、设备占用/无首帧要给出准确提示。窗口隐藏、最小化、遮挡、进入壁纸模式或启动页时暂停并释放透视 owner，返回前台时仅按用户原开关恢复。
- 摄像头自动化验收只能使用隔离 userData 和 Chromium fake camera，绝不能为了回归测试调用真实摄像头。当前假摄像头验收锁定：透视 `1280×720` / `readyState=4`，P10/P11 均保持 camera active 与 `scene.background===null`，透视+手势并存 `captureCount=1`。

## 2026-08-14：Wallpaper 与汽水的选择性融合边界
