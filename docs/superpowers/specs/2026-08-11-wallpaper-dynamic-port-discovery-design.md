# Windows 壁纸库动态端口发现

## 目标

Mac 端只通过 Windows Mineradio 的 UDP 广播和受限 HTTP ping 发现壁纸服务，支持服务端口变化，同时避免对整个局域网或完整端口范围产生探测流量。

## 发现顺序

1. 已保存的完整服务地址优先直连，并先请求 /api/ping。
2. 监听 UDP 45678 的 MINERADIO_WALLPAPER 广播。
3. 广播含合法 1024 至 65535 端口时，优先 ping 该完整地址。
4. 广播缺端口或该端口 ping 失败时，只对该广播 IP 探测 8123 至 8155。
5. 每个端口候选都必须收到 ok: true 的 /api/ping，才请求壁纸列表并保存为成功连接。

## 安全与性能

- 不扫描私有子网主机地址。
- 不扫描完整 1024 至 65535 端口范围。
- 受限端口扫描最多四个并发请求，使用短超时。
- 手动输入必须是 http 地址且明确指定 1024 至 65535 端口。

## 验证

覆盖动态广播端口、无端口回退、广播端口失败回退、并发上限、无广播不扫描、手动端口边界与缓存地址优先级。真实 Windows 广播和网络防火墙行为仍由实际两台设备验收。
