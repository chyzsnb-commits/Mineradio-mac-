# Windows 壁纸库连接与批量导入性能

## 目标

减少打开已保存 Windows 服务时的无效局域网扫描，避免查看详情时重建数百张远程卡片；同时允许用户选择当前筛选结果中的多张图片或视频，一次导入 Mineradio 的本地背景库。

## 设计

打开弹窗时先读取已保存的 Windows 地址并验证连接。连接成功后不再启动 UDP 和私网扫描；只有直连失败或没有保存地址时才发现局域网服务。连接过程采用单飞状态，避免重复打开或连续点击造成并发验证。

网格只在连接结果、搜索、类型筛选或排序变化时重建。打开或关闭详情只更新现有卡片的 `.active` 状态，保留已挂载的缩略图、滚动位置和可视区观察器。

多选状态与详情选中状态分离。卡片有独立勾选框，“全选当前结果”仅作用于当前搜索和筛选后的可见记录。批量导入顺序下载普通图片和视频，写入既有 IndexedDB 背景库，但不自动逐张应用为当前背景。已导入条目复用已有本地副本。Scene 因必须由 Windows 离屏渲染导出 MP4，未完成导出的条目明确跳过并留在选择中供用户后续在详情处理。

## 验证

- 专项测试覆盖缓存地址优先连接、详情不全量重建、多选、全选、顺序队列和 Scene 跳过。
- 动态模拟数百条记录，确认选择和关闭详情保留同一批卡片节点，且批量导入顺序执行。
- 完整 `npm run check`、相关语法检查和差异检查必须通过。
- 真正的 Windows 网络吞吐、远程媒体解码与 Scene 导出仍需要真实服务人工验收。
