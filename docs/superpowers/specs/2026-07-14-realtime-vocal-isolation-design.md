# 实时人声轨净化设计

## 目标

只优化实时模式中的“去伴奏、保留人声”，不继续修改已经可接受的伴奏轨，也不增加界面按钮。重点压低人声轨里的鼓点、镲片和带立体声扩散的乐器，同时保住主唱主体和基本齿音。

## 方案

- 继续复用现有一套左右声道 FFT，不增加第二个 Worklet，也不在音频帧内分配数组。
- 现有相位相干性、声道平衡和瞬态判断继续负责识别居中的稳定声音，并排除鼓点和左右声道乐器。
- 每个频谱帧额外统计 160-6000Hz 的中置信号，以及 1400-6000Hz 的人声共鸣/存在感能量。
- 用两段能量的比例生成“帧级人声置信度”：包含完整人声频谱的帧可正常通过；只有低中频、缺少人声共鸣的伴奏帧最多保留 20%。
- 人声空间置信度使用更陡的曲线，瞬态抑制从 90% 加强到 98%，进一步压低鼓点和不确定的乐器。
- 帧级置信度做轻量时间平滑，避免相邻帧直接跳变产生水声。

## 边界

- 该算法仍根据声道位置和频谱形状猜测，不能可靠区分“完全居中且频谱与人声相似”的乐器。
- 单独人声会比当前版本更薄、更像练唱参考轨；高质量结果继续使用已有 AI 分轨。
- 伴奏轨掩码、AI 双轨、升降 Key、麦克风和双 100% 原声旁路不变。

## 验证

- 合成主唱保留率不低于 70%。
- 人声轨中置鼓点泄漏从约 14.6% 压到 10% 以下。
- 带立体声扩散的乐器泄漏从约 63% 压到 25% 以下。
- 现有伴奏轨人声抑制、侧声道乐器保留和中置鼓点瞬态测试全部继续通过。
- 完整运行 `npm run check`、Electron 假媒体启动检查和未签名 arm64 目录包构建。
