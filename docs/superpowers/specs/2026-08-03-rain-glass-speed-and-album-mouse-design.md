# 雨境流速与封面鼠标视角设计

## 目标

预设 9 的玻璃水珠在整个滑落阶段持续遵循“水珠流速”设置。为当前歌曲的模糊专辑封面背景提供可选鼠标视角绑定，默认维持固定背景，且不改变歌词、相机或上传媒体。

## 设计

- 水珠滑落阻力不再随着 `slipRemaining` 的进度增长，只按水珠尺寸给出稳定阻力。现有流速系数继续同时驱动滑落加速度和终端速度，因此运行中的水珠也会持续响应滑条。
- 新增 `fx.albumBackgroundMouseBind`，默认 `false`，由「界面 → 背景媒体 → 封面鼠标视角」控制。状态与现有 FX 自动存档一起持久化。
- 复用 `queueParticlePointerFrame()` 的归一化画布鼠标坐标，避免新增第二个 `mousemove` 监听。开启时仅为 `#album-bg` 和 `#album-bg-next` 写入轻微 CSS 平移变量；`#custom-bg`、歌词舞台、上传图片/视频和预设相机不参与。

## 验收

- 流速滑条调整后，水珠在滑落后半程不会因进度增加而被额外减速。
- 开关默认关闭；开启后只有专辑封面背景跟随鼠标产生轻微视差，关闭立即复位。
- 雨境专项与全量 `npm run check` 全绿；在真实 Electron 可见窗口复核两种流速、开关状态及非封面背景不受影响。
