# 底栏入口归位与音域回响卡片收紧设计规格

## 目标

恢复底栏原有的 3D 歌单架图标和“词”按钮。前者继续调用现有 `toggleShelfFromControls()`，后者继续调用现有 `toggleLyricsPanel()` 并打开歌词校准；桌面歌词只在视觉控制台“歌词”页设置。

## 根因与修复边界

视觉控制台整理器通过 `appendChild()` 重排控件。其布局表错误引用了两个底栏节点，导致节点从底栏移动到控制台。布局表不再引用这两个节点；桌面歌词恢复为其自身的 `t-desktopLyrics`、锁定、动效、高亮、大小、透明度、高度和帧率控件。不会改变歌词舞台、播放链或其他预设。

## 音域回响入口

系列卡保留标题与三个互斥版本按钮，移除重复的说明文字。三个按钮统一为 36px 高，在同一行等宽排列；标题和副标题均单行省略，避免窄面板相互遮挡。普通预设卡尺寸不变。

## 验证

新增静态回归覆盖：底栏节点不再被控制台引用、桌面歌词设置控件存在、系列卡说明移除且三按钮尺寸与文本截断固定。再执行 `npm run check` 与真实 Electron 验收。
