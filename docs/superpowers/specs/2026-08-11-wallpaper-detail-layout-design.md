# Windows 壁纸库详情布局

## 目标

修复 Windows 壁纸库详情打开后覆盖并压缩缩略图网格的问题。详情的预览、操作和内部滚动区必须始终完整可见。

## 根因与取舍

现有详情抽屉使用绝对定位覆盖整个内容区，网格不会为它预留宽度；在中等窗口宽度下，固定宽度的抽屉与网格发生视觉挤压。仅缩小抽屉会继续压缩预览和操作区，不解决根因。

采用内容区 CSS Grid：宽屏时网格和详情各占独立列，详情列最小宽度为 `360px`、目标比例为内容区 `42%`；在视口不大于 `920px` 时，详情成为全宽唯一内容，网格暂时隐藏，关闭详情后恢复网格。详情继续使用自身纵向滚动，不改既有选择、关闭、预览、下载或导出逻辑。

## 验证

- 专项测试断言宽屏打开详情时存在独立右列，窄屏时详情为全宽并隐藏网格。
- Playwright 在 `1280×720` 以模拟 8 项记录打开详情，确认网格与详情重叠为 `0`。
- Playwright 在 `900×720` 确认详情完全落在内容区内，关闭详情后网格恢复。
