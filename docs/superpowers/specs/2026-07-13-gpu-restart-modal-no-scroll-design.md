# 显卡重启弹窗防横移设计

## 问题

切换显卡模式并选择稍后重启时，弹窗的自动焦点会让页面产生横向滚动，右侧露出大块黑色区域。

## 修复

- 保留弹窗打开后自动选中“稍后重启”，以及关闭后恢复到原显卡模式按钮的键盘体验。
- 两次焦点移动都使用 `preventScroll`，禁止浏览器为聚焦元素滚动页面。
- 不修改弹窗尺寸、视觉样式、显卡模式保存和重启流程。

## 验证

- 自动检查打开和关闭弹窗的焦点调用都带有 `preventScroll`。
- 在桌面和小窗口中打开弹窗、点击“稍后重启”，确认页面横向位置不变且右侧无黑边。
- 确认 Tab、Shift+Tab、Esc 和两个按钮仍可正常使用。
