# 显卡模式与启动页快速进入设计

## TL;DR

在现有高级参数中新增对称的三段式“显卡模式”控件，让用户选择自动、省电或高性能，并在选择后提供稍后重启与立即重启。启动页改为出现后即可点击或按键跳过，同时完整保留首页悬浮动画，只在应用进入现有后台省电状态时暂停。

## 背景

当前主界面和启动页创建 WebGL 上下文时都固定使用 `high-performance`。这会让普通使用场景也持续偏向高性能渲染，不符合用户希望自行控制发热与流畅度的要求。

当前启动页虽然显示“点击进入”，但点击只有在 5 秒计时结束后才有效。首页卡片和视觉元素的无限悬浮动画是产品核心视觉，不能删除或降低前台效果。

## 目标

1. 新增“自动 / 省电 / 高性能”显卡模式，默认使用自动。
2. 控件与现有分段按钮视觉一致，三项严格等宽、等高、间距一致。
3. 切换显卡模式后明确提示需要重启，并提供“稍后重启 / 立即重启”。
4. 启动页从第一帧开始就允许点击、回车或空格跳过。
5. 首页悬浮动画在前台完整运行，仅在现有后台省电状态下暂停，回到前台后恢复。

## 非目标

- 不删除或简化首页悬浮动画。
- 不改变用户已设置的渲染分辨率、刷新率或性能档位。
- 不在运行中销毁并重建主 WebGL 渲染器。
- 不承诺强制切换到某一块物理显卡。macOS 最终仍由系统决定实际设备，设置只提供 WebGL 的功耗偏好。

## 界面设计

在“高级参数”的性能区域按以下顺序排列：

1. 渲染分辨率
2. 总刷新率上限
3. 显卡模式
4. 性能档位
5. 负载与性能

“显卡模式”复用现有 `.fx-seg` 组件，使用一整行三等分按钮：

```text
自动 | 省电 | 高性能
```

三个按钮使用同一网格轨道，不设置单独宽度，不新增特殊颜色。选中状态沿用性能档位的玻璃高亮，保证面板纵向节奏和左右边界一致。

切换到与当前保存值不同的模式后，弹出项目现有风格的确认窗口：

```text
显卡模式将在重启后生效
[稍后重启] [立即重启]
```

“稍后重启”只关闭窗口；“立即重启”调用现有 `window.desktopWindow.restartApp()`。浏览器调试环境没有该接口时只保存设置并提示下次启动生效。

## 数据与渲染行为

新增独立本地设置键 `mineradio-gpu-mode-v1`，合法值为：

| 用户选项 | 存储值 | WebGL `powerPreference` |
| --- | --- | --- |
| 自动 | `auto` | `default` |
| 省电 | `low-power` | `low-power` |
| 高性能 | `high-performance` | `high-performance` |

读取到空值或非法值时回退到 `auto`。主界面 `THREE.WebGLRenderer` 和启动页原生 WebGL context 共用同一套归一化和映射规则，确保选择一致。

`powerPreference` 只能在创建 WebGL 上下文时设置，所以切换后不尝试热重建渲染器，避免黑屏、资源泄漏或播放中断。新值在下一次启动时生效。

## 启动页快速进入

移除“必须等待 5 秒后点击才有效”的交互门槛，但保留原动画与自动进入时机：

- 启动页可见后，第一次点击、回车或空格立即触发退出。
- 手动跳过使用约 200 毫秒的短淡出，避免闪屏。
- 跳过时停止启动音效和启动页绘制循环，清理原计时器。
- 必要的主页数据加载继续在后台执行；跳过只提前显示主页，不跳过初始化。
- 已开启“秒启动跳过启动页”的用户仍走现有完全跳过路径。
- 未进行操作时，启动页仍按原节奏展示，并在原定时间进入可见提示状态。

## 首页悬浮动画

前台 `body.empty-home-active` 下的卡片悬浮和视觉漂移保持现状，不改幅度、时长、缓动或清晰度。

当应用进入现有 `render-background-eco` 或 `render-deep-sleep` 状态时，通过 CSS 将首页无限动画设为 `animation-play-state: paused`。回到前台移除状态类后浏览器从原位置继续动画，不重新开始。现有“后台保持运行”模式仍按项目原规则覆盖省电状态。

## 异常处理

- 本地存储不可用或值损坏：回退自动模式，应用继续启动。
- 立即重启接口调用失败：保留已保存设置，提示用户手动重启。
- 启动页被连续点击：退出函数保持幂等，只执行一次。
- WebGL 不可用：继续使用项目现有降级路径，不因显卡模式新增失败点。

## 验证

### 自动检查

- `npm run check`
- `git diff --check`
- 对全部 `public/js/**/*.js` 和 `public/js/**/*.mjs` 执行 `node --check`

### 界面与行为检查

1. 三个显卡按钮在不同窗口宽度下同宽、同高、无文字溢出。
2. 三种模式分别保存正确，重启后仍保持选中状态。
3. 主界面与启动页创建 WebGL 时使用对应的 `powerPreference`。
4. “稍后重启”不重启，“立即重启”保存后正常重启。
5. 启动页第一秒内点击、回车和空格都能立即进入，连续触发不会重复执行。
6. 首页悬浮动画在前台完整运行；失焦、隐藏或最小化后暂停；回到前台继续。
7. 现有“秒启动”、性能档位、分辨率和刷新率设置不受影响。
